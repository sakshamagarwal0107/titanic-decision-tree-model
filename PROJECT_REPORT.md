# Titanic Survival Prediction with a Decision Tree

## Project goal
This project uses a decision tree to predict whether a passenger survived the Titanic disaster. The predictors are age, sex, passenger class, and fare. The target column is `survived` (0 = did not survive, 1 = survived).

## Dataset exploration
The public passenger dataset contains 891 rows. In the selected columns, age has 177 missing values; sex, passenger class, fare, and the survival label have no missing values. There are 549 passengers labeled 0 and 342 labeled 1. The script prints these counts and the missing-value summary when it runs.

## Steps followed

1. **Load data with Pandas.** The program uses Kaggle's `train.csv` if it is placed in `data/`; otherwise it downloads the public Titanic CSV. Column names are normalized to lowercase so both data sources work.
2. **Choose predictors and target.** The predictors are `age`, `sex`, `pclass`, and `fare`. The target is `survived`.
3. **Handle missing values.** A scikit-learn preprocessing pipeline fills numeric missing values with the median and missing sex values with the most common category. These imputers are fitted on training data only.
4. **Encode categorical data.** Sex is one-hot encoded, which converts categories such as female and male into numeric indicator features.
5. **Split and train.** The data is divided into 80% training and 20% test data with stratification and a fixed random seed. A decision tree is limited to depth 4 and requires at least 5 observations in a leaf to keep it easier to interpret.
6. **Evaluate.** The program reports accuracy, a confusion matrix, and precision, recall, and F1 for each class using the held-out test set.
7. **Explain the model.** The feature-importance chart ranks the transformed features by their contribution to impurity reduction in this fitted tree.

## Results and screenshots
Run `python titanic_tree.py` after installing the dependencies. It creates the measured results under `results/`:

- `evaluation_summary.png` — visual snapshot of holdout accuracy and the confusion matrix.
- `feature_importance.png` — graph of the most important features.
- `evaluation.txt` — accuracy, confusion matrix, precision, recall, and F1.
- `feature_importance.csv` — numeric feature-importance values.
- `report.md` — this method and the actual score/top feature filled in by the run.

Use the two PNG images as the output screenshots when placing this report in Google Docs. The exact accuracy and feature ranking are generated by the reproducible script; they depend on its fixed split and should not be guessed or treated as guaranteed performance.

## Findings to discuss
After running the script, use the top entry in `feature_importance.csv` to state which input most influenced this specific tree. Sex can appear as separate one-hot features, such as `sex_female` and `sex_male`. Importance is model-specific and does not establish that a feature caused survival. Accuracy is the share of held-out passengers classified correctly, not a guarantee about every passenger or future data.

## Limitations
This is a small historical dataset and an introductory model. A single train/test split gives only one estimate of performance. The tree can miss patterns, and feature importance can change with the split or model settings. It is for learning, not real-world survival decisions.
